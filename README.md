# Septic TikTok Malaysia

Analysis of Malaysian TikTok creators posting about septic tanks and wastewater, scraped with Apify.

- `index.html` — report page
- `scrape-tiktok.mjs` — scraper script (needs `APIFY_API_TOKEN` in `.env`)
- `tiktok-creators.csv` / `tiktok-videos.json` — scraped data

Run: `node scrape-tiktok.mjs`
